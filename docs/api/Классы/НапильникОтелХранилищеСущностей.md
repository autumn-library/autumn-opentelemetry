# НапильникОтелХранилищеСущностей

Напильник слоя репозиториев: оборачивает хранилища сущностей `autumn-data` в декоратор, который на каждый вызов метода создает спан и пишет длительность в гистограмму. Аналог инструментирования `spring.data.repository.invocations`.

## Описание

Применяется к бинам с прозвищем `ХранилищеСущностей` (хранилища, которые `autumn-data` регистрирует для каждой сущности) и к пользовательским хранилищам с аннотацией `&ХранилищеСущностей` на конструкторе. Методы берутся с фактического объекта, поэтому у пользовательского хранилища оборачиваются и его методы запроса, и унаследованные от `ХранилищеСущностей`.

Не оборачиваются методы, которые не ходят в БД: `ПолучитьОбъектМодели`, `ПолучитьПулСущностей`, `СоздатьЭлемент`, `Закрыть`.

Порядок: `&Порядок(503)` - после напильников аннотаций.

## Сигналы

| Сигнал | Имя | Атрибуты |
|--------|-----|----------|
| Спан INTERNAL | `{ИмяБина}.{ИмяМетода}` | `code.namespace`, `code.function.name`, `error.type` при ошибке |
| Гистограмма, с | `entity.repository.invocations` | `entity.repository`, `code.function.name`, `entity.repository.state` (`success` или `error`), `error.type` при ошибке |

Ошибка метода записывается в спан событием `exception` со статусом `Error` и доходит до вызывающего кода как обычно. Границы бакетов гистограммы - из семантических соглашений для клиентов баз данных (`ОтелСемантическиеСоглашения.ГраницыДлительностиОперацииБД()`).

Спан делается текущим на время вызова, поэтому операции entity и запросы к СУБД, которые выполняет метод, становятся его потомками.

## Конструктор

```bsl
&Напильник
&Порядок(503)
Процедура ПриСозданииОбъекта(&Табакерка &Пластилин("ОтелТрассировщик") ОтелТрассировщик,
		&Табакерка &Пластилин("ОтелМетр") ОтелМетр,
		&Деталька(Значение = "otel.enabled", ЗначениеПоУмолчанию = Ложь) ОтелВключен,
		&Деталька(Значение = "otel.entity.repository.enabled", ЗначениеПоУмолчанию = "") СлойВключен)
```

Напильник включен, когда включен `otel.enabled` и не выключен `otel.entity.repository.enabled`. Трассировщик и метр достаются из табакерок при первом обернутом бине, поэтому SDK не поднимается, если хранилищ в приложении нет.
