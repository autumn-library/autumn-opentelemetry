# НапильникОтелХранилищеСущностей

Напильник слоя хранилищ сущностей: находит в контейнере хранилища и отдает их инструментированию из `opentelemetry-instrumentation-entity`, которое оборачивает вызовы методов спанами и гистограммой.

## Описание

Применяется к бинам с прозвищем `ХранилищеСущностей`. Такое прозвище получают и хранилища, которые `autumn-data` регистрирует для каждой сущности, и пользовательские хранилища с аннотацией `&ХранилищеСущностей`.

Обертку строит [`ОтелИнструментированиеХранилищаСущностей`](https://github.com/nixel2007/opentelemetry-instrumentation-entity/blob/master/docs/api/ОтелИнструментированиеХранилищаСущностей.md) — там же описано, какие методы оборачиваются и какие сигналы пишутся. Если оборачивать нечего, бин остается нетронутым.

Порядок: `&Порядок(503)` - после напильников аннотаций.

## Конструктор

```bsl
&Напильник
&Порядок(503)
Процедура ПриСозданииОбъекта(&Табакерка &Пластилин("ОтелТрассировщик") ОтелТрассировщик,
		&Табакерка &Пластилин("ОтелМетр") ОтелМетр,
		&Деталька(Значение = "otel.enabled", ЗначениеПоУмолчанию = Ложь) ОтелВключен,
		&Деталька(Значение = "otel.entity.repository.enabled", ЗначениеПоУмолчанию = "") СлойВключен)
```

Напильник включен, когда включен `otel.enabled` и не выключен `otel.entity.repository.enabled`. Трассировщик и метр достаются из табакерок при первом обернутом бине, поэтому SDK не поднимается, если хранилищ в приложении нет.
