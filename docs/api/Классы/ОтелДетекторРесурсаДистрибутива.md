# ОтелДетекторРесурсаДистрибутива

Детектор ресурса дистрибутива: сообщает, что SDK собран библиотекой `autumn-opentelemetry`.

## Описание

Реализует `ИнтерфейсДетекторРесурса` ядра opentelemetry. Желудь с прозвищем `ДетекторРесурса`: `ОтелSdk` сливает его ресурс с остальными детекторами.

## Атрибуты ресурса

| Атрибут | Значение |
|---------|----------|
| `telemetry.distro.name` | `autumn-opentelemetry` |
| `telemetry.distro.version` | версия установленного пакета `autumn-opentelemetry` |

Адрес схемы ресурса — `https://opentelemetry.io/schemas/1.44.0`.

## Методы

```bsl
Функция Обнаружить() Экспорт
```
